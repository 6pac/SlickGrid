# Migration guides

Each major version of SlickGrid has breaking changes. Upgrade one major version at a time, and follow the guide for each version you pass through.

| Version | Guide | Main changes |
| ------- | ----- | ------------ |
| 6.x | [Migrating to v6](/migration/v6) | Pinning and sticky docking replace frozen panes, hidden columns stay in the column array, SortableJS is dropped (no runtime dependencies), ESM only |
| 5.x | [Announcing v5.0](https://github.com/6pac/SlickGrid/wiki/Major-version-5.0-%E2%80%90-ES6-ESM-and-TypeScript-Support) | Migration to TypeScript with ES6/ESM builds, and the new Alpine theme |
| 4.x | [Announcing v4.0](https://github.com/6pac/SlickGrid/wiki/Major-version-4.0---Removal-of-jQuery-requirement) | jQuery is no longer required; the grid uses native browser code |
| 3.x | [Announcing v3.0](https://github.com/6pac/SlickGrid/wiki/Major-version-3.0----Removal-of-jQueryUI-requirement-(replaced-by-SortableJS)) | jQuery UI is replaced by SortableJS |
