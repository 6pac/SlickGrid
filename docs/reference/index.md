# API Reference

This reference is generated directly from the SlickGrid TypeScript source, so signatures, types, defaults and descriptions always match the code.

Each area is one long page with a scroll-spy contents panel on the right. Use the **Section / A–Z** toggle to switch between grouped and alphabetical views, or the [A–Z index](/reference/a-z) to find any member by name across all areas.
