Variable row height + pinning (rowHeightProvider + pinning)

Grid A — two pinned columns

Grid B — two pinned columns + three pinned rows

About

Both grids use a rowHeightProvider (every 13th row 70px, every 5th row 32px, else 25px). Grid A pins the first two columns; Grid B pins the first two columns and the first three rows. The checks assert that the single viewport keeps the provider heights and that both grids expose the expected pinning configuration.
