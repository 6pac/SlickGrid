Demonstrates:

  • the ready-made pivot table (SlickPivotTable): a toolbar, the pivot grid, a resizable PivotTable Fields pane, a status bar and a details dialog, from one constructor; the options above the line are the example's own
  • an Excel style PivotTable Fields pane (SlickPivotPanel): check fields, drag them between the Filters, Columns, Rows and Values areas, reorder them, or drag them out to remove them; drag the splitter (or use its arrow keys) to resize it, and hide or show it with Field List
  • the ▾ pill menus (also opened with Enter): move, filter, sort, Summarize Values By (Sum, Count, Average…) and the Value Field Settings (every aggregator, show values as, number format)
  • keyboard: Alt+↑/↓ moves a pill, Alt+←/→ moves it to another area, Delete removes it
  • the toolbar (SlickPivotToolbar): compact, outline and tabular layouts, subtotals, grand totals, Expand All and Collapse All
  • sorting by label (row label header) or by value (value column header)
  • double-click a cell to list its source rows in a sortable grid (SlickPivotDetails)
  • "Defer layout update", saving the layout, and an asynchronous (simulated server) provider
  • automatic date hierarchy: checking Order Date groups it by years, quarters and months, like Excel; each level is also listed below the date field
  • write-back: with "Edit values", type a new total into a Sum of Units cell (subtotals and grand totals too) and it is spread over the source rows behind it, keeping their proportions; Undo and Redo in the toolbar (or Ctrl+Z and Ctrl+Y) restore them exactly
  • pinned or sticky grand totals (the column group headers follow docked columns), and a right-to-left grid

The "Excel sample" dataset is the one from issue #1020; its pivot gives 3, 7 and 10 as in Excel.
