Demonstrates:

  • an ordinary grid (a DataView and its columns) with two plugins registered on it: the pivot (SlickPivot) and the MS Access style crosstab designer (SlickPivotDesigner), added above the grid
  • the design grid of the MS Access query designer: one column per field, with its Field, Total (Group By, Sum, Avg, Min, Max, Count, StDev, Var, First, Last, … or Where), Crosstab (Row Heading, Column Heading, Value), Sort and Criteria
  • add a column by double-clicking a field (or pressing Enter on it), dragging it onto the design grid, or picking it in the last column; move or remove a column with the buttons of its header
  • a Row Heading with a Total other than Group By is a row total (Total Of Amount), shown after the row headings like in MS Access
  • MS Access criteria, kept as text in the spec (PivotFilter.criteria): 2024, >= 100, "East" Or "West", Between 10 And 50, In ("Coffee", "Brie"), Like "S*", Not "North", Is Null
  • an MS Access style result: tabular, with the item captions on every row, no subtotals and no grand total row
  • Pivot Mode (the switch of the designer): off, the grid shows its own rows and columns again; on, it shows the crosstab

See the PivotTable Fields example for the Excel style UI.
