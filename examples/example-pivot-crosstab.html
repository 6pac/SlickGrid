Demonstrates:

  • the pivot API without a field list: an MS Access crosstab query (row headings, a "Qtr n" column heading with a fixed list of items, a "Where" filter and a row total)
  • derived fields (getter) and lookup fields reading related tables, like the Power Pivot data model
  • distinctCount, a custom aggregator (quantity weighted discount) and measures computed after aggregation, correct at every subtotal level
  • "Show Values As": % of the parent row total
