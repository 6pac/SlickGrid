Example - Auto Header Height

⌂ Search:




Demonstrates:

  • auto-sizing header height to fit multi-line column titles
  • no clipping of header content when titles wrap to multiple lines
  • opt-in feature with autoHeaderHeight grid option (disabled by default)
  • works with both single-line and multi-line headers
  • dynamic recalculation on column resize
  • frozen column support with equalized left/right header heights
  • minimal configuration (just set autoHeaderHeight:true)
