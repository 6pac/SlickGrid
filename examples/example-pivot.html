Demonstrates:

  • multi column pivoting with the SlickPivot plugin
  • an MS Access style crosstab: two row headings, one column heading with a fixed list of items (D, C, B, A), four values per item and row totals ("All") in front
  • a row level calculated field (Ratio) and custom column templates and formatters

See the PivotTable Fields example for the interactive (drag & drop) version.
